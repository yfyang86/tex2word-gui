# Sprint 04 — Tab completion, symbols, environments, macros

## Goal

Make Tab the completion key, with a key map that never fights the browser or
traps keyboard users; add a palette of common symbols with real glyph
previews; round out environment and macro support.

## Key map (editor textarea)

| State | Key | Action |
| --- | --- | --- |
| list open | ↑ ↓ / Ctrl+P Ctrl+N · PgUp PgDn | move · jump 8 |
| | **Tab** / Enter | accept (Shift+Enter: close and newline) |
| | Shift+Tab | move up |
| | Esc · ← → Home End | close (arrows also move the caret) |
| in a snippet | **Tab** / Shift+Tab | next / previous stop (past the last: leave) |
| | Esc | leave the snippet |
| otherwise | **Tab** | indent a multi-line selection · expand an environment name typed alone on a line (`itemize` → `\begin{itemize}…\end{itemize}`) · complete a unique match · open the list when several match · else insert two spaces |
| | Shift+Tab | outdent the line / selected lines |
| | Ctrl/Cmd+Space | open the list |
| | **Esc, then Tab** | move focus out of the editor (no keyboard trap) |
| | Enter after `\begin{env}` | add the matching `\end{env}` |

Ctrl/Cmd/Alt+Tab and keys during IME composition are never intercepted.
Indent and every insertion go through `execCommand("insertText")`, so undo
works for all of them. Snippet tabs are converted to the editor's two-space
indent. Accepting a completion inside a snippet stop (e.g. a label inside
`\ref{}`) keeps the outer snippet's remaining stops in step.

## Symbols

- `app/static/symbols.js` — ~250 commonly used symbols in ten groups (Greek,
  operators, relations, arrows, big operators, delimiters, misc, sets & fonts,
  accents, text), each with its glyph, math/text mode, package and an
  optional argument snippet. Single source for everything below.
- `app/static/symbols.svg` — an SVG sprite generated by
  `scripts/build_symbols.py` from that list, with glyph **outlines** taken from
  STIX Two Math (SIL OFL 1.1; attribution kept in the file). Previews therefore
  look identical in every browser with no web font. Accents are composed from
  combining marks centred over the base glyph.
- **Completion popup** shows the glyph next to each symbol command.
- **Symbol palette** (Ω button in the editor header): search, group tabs, a
  "Recent" row, a hint line naming the hovered command and its package.
  Clicking inserts at the caret; a math-only symbol typed outside math is
  wrapped in `$…$`. Enter in the search box inserts the first match; Esc
  closes and returns to the editor.

Regenerate the sprite after editing `symbols.js`:

```bash
npm pack @fontsource/stix-two-math && tar -xzf fontsource-stix-two-math-*.tgz
uv run --no-project --with fonttools python scripts/build_symbols.py \
    package/files/stix-two-math-latin-400-normal.woff
```

(`tests/js/symbols.test.js` fails if a symbol has no sprite.)

## Environments, macros and more

- `\begin` / `\end` are now commands: accepting them drops straight into the
  environment list; `\end{` still offers the innermost open environment.
- Bare environment word + Tab at the start of a line expands the full block
  (catalog and project environments).
- Macros: `\newcommand{\x}[n][default]` (the optional first argument is left
  out of the snippet and arguments keep their `#n` numbers), `xparse`
  `\NewDocumentCommand` signatures (`s`, `o`, `O{…}`, `m`, …), `\def`,
  `\DeclareMathOperator`; the popup shows the definition (`→ \left\| #2 …`).
- Colours: `\textcolor{`, `\color{`, `\colorbox{`, … complete xcolor's base
  colours and project `\definecolor`/`\colorlet` names, each with a swatch
  (HTML, rgb, RGB, gray and cmyk models).
- `\label{` suggests a name: a prefix from where it sits (figure → `fig:`,
  table → `tab:`, equation → `eq:`, theorem-likes, a heading → `sec:`) plus a
  slug of the caption or heading, de-duplicated against existing labels.
